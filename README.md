# Mobile Portfolio and Risk Tracker App (Riskfolio)
## Project Description
This mobile application allows users to track their investments across multiple assets (BIST, Gold, Forex, SPY) and provides a unique assessment tool to determine their investor profile on a scale of 1 to 7.
